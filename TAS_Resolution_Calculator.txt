This tool calculates the resolution function of a triple-axis spectrometer (TAS) based on the instrument configuration and sample geometry. Users provide the lattice parameters, scattering plane, spectrometer configuration (e.g., monochromator/analyzer arrangement, focusing conditions, and collimation), and the scan range. For calculations using the Popovici approximation, additional information about the instrument component dimensions is required; default parameters are provided for CTAX@HFIR and HER@JRR-3.
